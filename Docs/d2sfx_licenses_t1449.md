# t1449 source licences

Every source file actually used in a rendered output is listed below.
Licence was checked on each file's own OpenGameArt or Internet Archive page.
Only CC0 / public-domain (or clearly commercial-OK with no attribution required) material was used.
Raw sources live in `_sources/`. This pack does not contain copyrighted or game-ripped audio.

## Policy notes

- Freesound full downloads redirected to `/home/login/` without an account. No account or API key was created. Freesound would need a free login or an API key (`client_id` / `client_secret` from https://freesound.org/apiv2/apply) to use CC0 items from that site.
- Skipped after a page check (not used, not in `_sources/`): CC-BY 3.0 *Aargh! (male screams)* and *11 male human pain/death sounds*; CC-BY-SA 4.0 *DAMAGE SOUNDS (Male)* and *EFFORT SOUNDS (Male)*.
- Licence doubts, also skipped: OpenGameArt *Gorilla Sounds* (page is tagged CC0 but credits J0ck0 / mediacollege.com, third-party licence not independently verified); Internet Archive *Wayzata Technology 1995 Sound Effects* (uploader-tagged CC0, likely still a commercial library).
- USFWS field recordings are U.S. government works in the public domain. The Archive item asks for credit if possible; it is given here. Attribution is not required.
