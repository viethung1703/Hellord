HELLORD FX t1481: 3 FIRE BASIC MAIN ATTACKS (Magma Throw, Rolling Magma Rock, Fire Pillar)
=======================================================================================
MOCKUP ASSETS, UNTESTED IN UNITY. Generated by firebasics_gen.py (deterministic, hand-keyed tables + fixed analytic patterns, no rng, no AI art). Sprites are alpha 0/255, Endesga fire ramp
3e2731 / 733e39 / be4a2f / d77643 / f77622 / feae34 / fee761 (+181425 outline ink, ffffff only as tiny cores). All strips are one horizontal row of frames, point filter, no mipmaps, 16 PPU,
30 fps unless stated. "pivot" is in px from the top-left of one frame.
Rebuild: python3 firebasics_gen.py (strips) ; python3 contact_sheet.py ; python3 render_mockup.py all|mt|rr|pf

SPAM / FLOOD GUARD (all three): short lifetimes, nested-dither decal fade, caps below. Fire is hot orange/yellow with dark N3E backing on the sides/base only, no red fills, no rings/discs/washes.

CAVEATS
-------
* Untested in Unity: nothing was imported; the pivots/timings are the proposed values of the mock-up code, not game code. Glow is a numpy simulation only.
* The reference footage was limited: PoE2 Molten Blast footage in beta/test videos was too dark to measure, so the burst look comes from the Nova clip + wiki numbers; the D2R boulder tail was measured only qualitatively
  (about 2 -> 8-12 diameters, trail about 1.5 s). The ref tail is MUCH longer than ours on purpose (spam readability). Rolling Magma (PoE2) is only a loose reference.
* The Fire Pillar is derived from the boulder-impact plume (D2R Volcano/Fissure/Meteor footage was too small/noisy at 720p); its eruption look is my interpretation, not a copy.
* Roll 16-dir rows are rendered analytically (tail rotated per direction), not rotated bitmaps; the dir16 strip is large (560x896). If memory matters, rows can be halved (8 dirs + flip) with the generator.
* The hit spark is baked east only; rotation in Unity will resample pixel art (use nearest, or bake rows if it looks soft).
* Decal fade times above are the mock-up's values (accelerated a little vs. the blood decals) and can be stretched by the code.
